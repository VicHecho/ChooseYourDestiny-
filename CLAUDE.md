# Choose Your Destiny — project notes

## Hack The Matrix course access rules (subject to change)
- Price: $33 for the 30/31-day course (length follows the month).
- Program days always follow the calendar: Day N = the Nth of the month. Daily classes and emails follow the same dates.
- A purchase grants Day 1 through the last day of the month.
- Mid-month joiners (e.g. buy on the 15th): the purchase covers Day 1–31 of the FOLLOWING month. Until then they can view past content and join the current ongoing class right away.
- Discord: https://discord.gg/dgXjGTa7Q
- Code sequences for all 31 days: shopify/book/codes-31.json. Book text: shopify/book/.
